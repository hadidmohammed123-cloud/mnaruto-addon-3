BUILD THE JAR (pick one)

A) On your PC: install JDK 17 + Gradle 8.1.1, open a terminal in this folder, run:  gradle build
   Jar appears in build/libs/  (use the one WITHOUT "-sources"/"-slim" in its name).

B) No installs: create a free GitHub repo, upload this folder's contents, open the
   Actions tab -> "build" -> Run workflow. Download "NarutoModAddon-1.20.1-jar" when it finishes.

Put the jar in your mods folder next to ShinobiCraft 0.3.2 (Forge 47.4.28, Minecraft 1.20.1).
